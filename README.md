# PEBMedia Test Project

Modern, responsive one-page website concept for Frydrych Stavby, a construction company based in Liberec, Czech Republic.

## Technologies

- HTML5
- CSS3
- JavaScript
- Jquery

## Run locally

1. Clone the repository:

   git clone https://github.com/Shilpavora04/PEBMedia-Test-Project.git

2. Open the project folder.

3. Open `index.html` in a modern web browser.

No additional dependencies or build process are required.

## Live Preview

https://shilpavora04.github.io/PEBMedia-Test-Project/ 
The project is deployed using GitHub Pages.

## Deployment

The website can be deployed through GitHub Pages by selecting:

- Branch: `main`
- Folder: `/(root)`
